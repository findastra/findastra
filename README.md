### Astra's PetOS -- intelligent apps on Windows

Astra's PetOS is a free, open-source platform I'm building on Windows. The pets are intelligent apps, and the Friendly Farmer organizes the Farm.

The design connects four layers: the programs and tools you use; a pet dashboard that manages them; an agentic harness with an AI model for help on demand; and **You**, the human. Asking before consequential actions is part of the design.

[Farm plans and catalog](https://github.com/findastra/astras-pet-os) · [System Map](https://findastra.github.io/astras-pet-os/system-map-20261012.html)

Each number below is a stable catalog ID. The exact stages -- registered, pipeline, seed and roadmap -- record catalog status, not release, testing or integration guarantees. Descriptions summarize each animal's scope; unfinished work is labelled as planned. A public repository alone does not prove its program works.
