### Astra's PetOS -- intelligent apps on Windows

Astra's PetOS is a free, open-source platform I'm building on Windows. The pets are intelligent apps, and the **Friendly Farmer** organizes the Farm.

The design connects four layers: the programs and tools you use; a pet dashboard that manages them; an agentic harness with an AI model for help on demand; and **You**, the human. Asking before consequential actions is part of the design.

[Full pet catalog and Farm plans](https://github.com/findastra/astras-pet-os) · [System Map](https://findastra.github.io/astras-pet-os/system-map-20261012.html)

Each number is a stable catalog ID. **Registered**, **pipeline**, **seed** and **roadmap** describe development status, rather than release or testing guarantees. Descriptions give each project's scope; integrations vary by project, and planned connections are labelled.
